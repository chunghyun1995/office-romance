# 오피스 로맨스: 첫 일주일

판교의 게임 회사 '넥스트웨이브'에 입사한 신입 기획자의 첫 7일.
세 명의 동료와의 관계가 선택에 따라 달라지는 브라우저 연애 시뮬레이션입니다.
첫 일주일의 고백 이후에는 자취방·주말 여행 데이트와 세 달 뒤의 후일담이 이어집니다.

**플레이:** GitHub Pages 주소에서 바로 실행 (설치 불필요, PC·모바일 지원)

## 등장인물 (모두 성인)
- **한서윤** (31) — 라이브 기획 파트장. 날카로운 여우상, 단정한 블라우스와 슬랙스. 주인공의 사수.
- **윤하린** (21) — UI 디자이너, 경력 입사 동기. 순한 강아지상, 슬림한 체형, 흰 티셔츠와 데님 핫팬츠.
- **정유나** (25) — 마케팅팀. 도도하고 차분한 고양이상, 오프숄더 니트와 흰 핫팬츠.

## 시스템
- 7일 일정, 선택지마다 호감도 변화 → 일요일에 루트 결정
- 고백 이후 캐릭터별 데이트: 자취방 또는 숙소 선택, 함께 머물기 또는 배웅하기, 다음 날과 세 달 뒤 후일담
- 로맨스는 대화·손잡기·포옹·키스와 암전 연출로 구성됩니다.
- 엔딩 4종 (히로인별 엔딩 3 + 노멀 엔딩), 엔딩 수집 기록
- 저장/불러오기 5슬롯, 자동 진행, 읽은 대사 스킵(Ctrl 누르면 강제 스킵), 대사 로그, 호감도 확인

## 조작
클릭 / Space / Enter: 다음 대사 · Ctrl(누르고 있기): 스킵 · Esc: 창 닫기

## 일러스트 교체
실사풍 AI 생성 이미지 43종을 포함합니다. 캐릭터 3명의 표정 6종씩과 배경·데이트 장면 25종입니다.
캐릭터는 2048×3072px, 배경·데이트 장면은 긴 변 2560px입니다. 원본 AI 생성 이미지를 Lanczos 방식으로 업스케일한 출력이며 네이티브 2K 생성은 아닙니다.
캐릭터는 투명 WebP로 제공하며, 기존 장면과 등장인물 소개에 자동으로 연결됩니다.
생성에 사용한 최종 프롬프트는 `ASSET_PROMPTS.json`에 기록했습니다.
브라우저에서 `index.html`을 열거나 GitHub Pages로 플레이할 수 있습니다.

## 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 |
| `engine.js` | 비주얼노벨 엔진 (스크립트 해석, 세이브, 이미지 로딩) |
| `story.js` | 시나리오 스크립트와 캐릭터·배경 정의 |

시나리오 문법은 `story.js` 맨 위 주석을 참고하세요.


## 하린의 헬스장 데이트

연애 후일담에서 헬스장을 선택하면 산호색 스포츠 브라탑과 검정 돌핀 팬츠 차림의 하린 CG가 표시됩니다. 함께 몸 풀기 또는 각자 운동하기를 선택하고, 운동 후 점심 약속을 거쳐 기존 엔딩으로 이어집니다. 내장 image_gen으로 생성한 CG는 긴 변 2560px로 Lanczos 업스케일했습니다. 생성 프롬프트와 해상도는 ASSET_PROMPTS.json에 기록했습니다.
