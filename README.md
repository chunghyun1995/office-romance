# 오피스 로맨스: 첫 일주일

판교의 게임 회사 '넥스트웨이브'에 입사한 신입 기획자의 첫 7일.
세 명의 동료와의 관계가 선택에 따라 달라지는 브라우저 연애 시뮬레이션입니다.

**플레이:** GitHub Pages 주소에서 바로 실행 (설치 불필요, PC·모바일 지원)

## 등장인물 (모두 성인)
- **한서윤** (29) — 라이브 기획 파트장. 주인공의 사수. 차갑지만 누구보다 오래 회사에 남아 있는 사람.
- **윤하린** (26) — UI 디자이너, 경력 입사 동기. 밝고 시끄럽고, 이번엔 꼭 출시되는 걸 만들고 싶다.
- **정유나** (27) — 마케팅팀. 조용히 옥상에서 도시락을 먹는, 도와달라는 말을 못 하는 사람.

## 시스템
- 7일 일정, 선택지마다 호감도 변화 → 일요일에 루트 결정
- 엔딩 4종 (히로인별 엔딩 3 + 노멀 엔딩), 엔딩 수집 기록
- 저장/불러오기 5슬롯, 자동 진행, 읽은 대사 스킵(Ctrl 누르면 강제 스킵), 대사 로그, 호감도 확인

## 조작
클릭 / Space / Enter: 다음 대사 · Ctrl(누르고 있기): 스킵 · Esc: 창 닫기

## 일러스트 교체
실사풍 AI 생성 이미지 36종을 포함합니다. 캐릭터 3명의 표정 6종씩과 배경 18종입니다.
캐릭터는 투명 WebP로 제공하며, 기존 장면과 등장인물 소개에 자동으로 연결됩니다.
생성에 사용한 최종 프롬프트는 `ASSET_PROMPTS.json`에 기록했습니다.
브라우저에서 `index.html`을 열거나 GitHub Pages로 플레이할 수 있습니다.

## 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 |
| `engine.js` | 비주얼노벨 엔진 (스크립트 해석, 세이브, 이미지 로딩) |
| `story.js` | 시나리오 스크립트와 캐릭터·배경 정의 |

시나리오 문법은 `story.js` 맨 위 주석을 참고하세요.
